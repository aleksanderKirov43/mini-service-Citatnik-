# Мини-сервис "Цитатник"

Простой REST API-сервис для хранения и получения цитат. 
Реализован на Go **без фреймворков**. Данные хранятся **в памяти**.
При перезапуске приложения данные будут потеряны.

---

## Запуск

```bash
go run ./cmd/
```
Сервис будет доступен по адресу: http://localhost:8080

## API эндпоинты

Добавить цитату POST http://localhost:8080/quotes

Тело запроса (JSON):
```json
{
  "author": "Фёдор Достоевский",
  "quote": "Жизнь задыхается без цели."
}
```
Ответ:

```json
{
    "id": 1,
    "author": "Фёдор Достоевский",
    "quote": "Жизнь задыхается без цели."
}
```

## Получить весь список цитат

GET http://localhost:8080/quotes

## Получить список цитат по автору
GET http://localhost:8080/quotes?author=Достоевский

Цитаты по автору (Достоевский):
```json
[
    {
        "id": 2,
        "author": "Фёдор Достоевский",
        "quote": "Если хочешь победить весь мир, победи себя."
    },
    {
        "id": 3,
        "author": "Фёдор Достоевский",
        "quote": "Сострадание есть главнейший и, может быть, единственный закон бытия всего человечества."
    },
    {
        "id": 1,
        "author": "Фёдор Достоевский",
        "quote": "Жизнь задыхается без цели."
    }
]
```

## Получить случайную цитату

GET http://localhost:8080/quotes/random

## Удалить цитату
DELETE http://localhost:8080/quotes/{id}

Ответ:
```json
204 No Content — при успешном удалении

404 Not Found — если цитата не найдена
```


## Примечания
- Цитаты хранятся в оперативной памяти, после перезапуска сервиса все данные удаляются.

- При добавлении цитаты оба поля (author, quote) обязательны.

- Поиск по автору реализован по подстроке, без учёта регистра.
